자료 추가

원본 주소는 등록 후 바꾸지 않습니다. 다른 주소는 새 자료로 추가해 주세요.

개선 후보로 저장하려면 본문을 확인하고 위 세 항목을 채워야 합니다. 이 기록은 기능 구현이나 법적 문제 없음의 인증이 아닙니다.

자료 목록 가져오기

자료 목록 JSON 배열을 선택한 뒤 내용을 확인하고 등록하세요. 한 파일에 최대 100개·240 KiB까지 받습니다. 더 큰 목록은 파일을 나눠 주세요.

각 항목에는 url과 title이 필요합니다. 선택 항목: projectId, readingStatus, decision, summary, application, riskNotes. 프로젝트 연결에는 YENO 프로젝트 ID를 사용합니다.

등록은 목록 전체를 함께 처리합니다. 기존 주소와 내용이 모두 같은 항목은 재사용하고, 내용이 충돌하면 아무 항목도 추가하지 않습니다. 링크의 본문은 가져오지 않습니다.
