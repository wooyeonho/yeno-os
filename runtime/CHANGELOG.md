# YENO runtime 변경 이력

## 0.1.0 — 첫 실행 코어

- 기존 마스터플랜을 토대로 별도 폴더에 새 실행 코어 구현.
- 휴대폰 크기에 대응하는 조종 화면, 연결 키 인증, 기본 명령 처리.
- 영구 기억·작업 큐·원문 기반 문서·상태 진단·개선 후보 파일 생성.
- 작업 중단·재개·취소, 전체 멈춤, 모듈·실행 규모 조절.
- 기억·설정 저장 지점과 복원, 원자적 저장·직전 백업·단일 작성자 잠금.
- 선택적 AI 작성 어댑터, 유료 호출 기본 비활성.
- Windows 실행 버튼 및 개인 네트워크 휴대폰 연결 실행기.
- 실제 통합 검증 13건과 실행기 확인. 범위와 미검증 항목은 VERIFICATION.md 참고.

기존 `C:\JARVIS_INSTALL\jarvis-os`와 Obsidian Vault는 읽거나 변경하지 않았습니다.

## 0.1.1 - 첫 사용 제어 보완 (2026-09-07)

- npm start를 launch.mjs로 통일해 로컬 설정을 동일하게 적용.
- 전체 정지 잠금 해제 후 개별 재개를 기다리도록 변경하고 회귀 검사 추가.
- 명령창·빠른 작업의 응답 유실 시 같은 요청 ID와 본문을 탭에 보존하고 재시도.
- 재시도 상태 수명 검사 6개 추가. 별도 기억·스냅샷 폼은 후속 범위.
- 실제 Windows·폰·브라우저·유료 모델 검증은 미완료 상태를 유지.
