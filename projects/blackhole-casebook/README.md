# V11 — BLACKHOLE 기록실 — 검색 추리 게임

2026-09-11: 소유자의 기능/프로젝트 전환 요청으로 만든 신규 프로젝트. 검색 추리 게임을 좋아하는 한국어 사용자가 약 3~5분의 오리지널 사건을 플레이하는 첫 시제품이다. 첫 결과물은 `BLACKHOLE_CASEBOOK.html`이다. 파일 하나를 브라우저로 열면 검색→기록 읽기→근거 대조→결말→진행 저장/복원이 동작한다. 계정·서버·API·결제가 필요 없다.

## 기존 계보와 차이

- B04는 여러 작품의 이야기/IP 관리 스튜디오다. 이 프로젝트는 B04의 이야기 제작 능력을 재사용할 독립 게임 제품이다.
- V09는 실제 역사와 가상 분기의 시뮬레이션이다. V11은 허구의 기록을 검색해 추리하는 제한된 사건 게임이며 V09를 덮어쓰지 않는다.
- 원본 49개 프로젝트는 유지한다. 신규 제품을 만들라는 최신 요청에 따라 V11 하나만 추가한다.

## 원자료 검토와 응용

사용자가 보낸 No Results Found Instagram 자료는 보존하며 원문 영상은 미확인이다. 별도로 [제작자의 Steam 소개](https://store.steampowered.com/app/4911390)를 2026-09-11 읽었다. 제작자는 단어 검색으로 기록을 발견하는 추리 방식을 설명한다. 해당 링크와 과거 SNS 게시물이 같은 콘텐츠를 소개하는지까지 확정한 것은 아니다.

검색으로 단서를 발견한다는 구조만 참고했다. 사건·인물·대사·UI·코드·이미지는 가져오지 않았다. 이 초기판의 「사라진 내일」은 새로 작성한 허구다. 원 게임이 무료라는 표시는 재배포·소스 이용 허가가 아니다. 타사 상표나 콘텐츠를 자사 자산으로 표시하지 않는다.

## 실행과 검사

```sh
node projects/blackhole-casebook/build.mjs
node --test projects/blackhole-casebook/engine.test.mjs
```

실행 검사 2/2 통과: 단서 순서로 결말 도달, 저장/복원, 잘못된 결론/부족한 근거, 잘못된 저장 파일과 중복 읽기. 시제품은 로컬 진행 상태만 저장하며 코어/계정 동기화는 없다. 모바일 브라우저의 파일 열기와 저장 지원은 실기기 확인 전이다. 전체 원본 데이터가 클라이언트에 포함되므로 유료 게임의 스포일러 방지 설계가 아니다.

첫 외부 검증 과제: 실제 사용자가 도움말 없이 사건을 끝내는지, 재미와 막힘 지점을 확인하고 사건 수/분기를 늘릴지 결정한다. 현재 매출·고객·인기 증거는 없다. 이번 작업에 외부 발송·공개 출시·유료 도구 연결은 포함하지 않는다.
