# A03 한끼안부 — 첫 로컬 실행본

원본 프로젝트 ID: `327a7cca-59b3-4a43-a536-41330d7a2246`. 기존 한끼안부의 요청·응답·미응답 상태 엔진을 구현했다. 새 프로젝트를 만들지 않았다.

`BLACKHOLE_HANKKI.html`을 브라우저에서 열면 별도 설치나 모델 키 없이 자신의 식사 응답을 남길 수 있다. 이 브라우저 저장에 동의한 뒤 새 식사 확인 → 먹었어요/아직이에요 → 기록 확인 순서다. 서버·가족 공유·푸시 알림·AI는 연결되지 않은 단일 기기 실행본이다. 가족에게 안부가 전달됐다고 표시하지 않는다. 기한이 지난 미응답을 건강 이상으로 해석하지 않는다.

## 구현

- 원본 목표에 맞는 요청·응답·취소·미응답, 4시간 응답 기한. UTC 저장과 서울/뉴욕/미국 서부 표시를 분리.
- 요청 ID로 중복 방지. 응답을 재전송하거나 다른 답으로 덮어쓰는 요청 거부.
- 브라우저 저장, 일시정지/재개. 재개가 이전 요청을 자동 응답시키지 않음.
- 백업 AES-256-GCM, PBKDF2-SHA256 210,000회, 암호 12자 이상. 복원 전 인증·형식 검사, 복원 후 일시정지. 저장된 데이터와 백업은 구분: 브라우저 내부 기록은 암호화하지 않는다.
- 연락처·위치·외부 스크립트 없음. 외부 네트워크 연결을 CSP로 제한. Web Locks 지원 브라우저 필요. 브라우저 저장 실패 시 완료로 표시하지 않음.

클라우드 브라우저에서 로컬 HTML을 여는 동작이 URL 보안 정책으로 차단됐다. 우회하지 않았다. 따라서 브라우저 버튼 조작·시각 검사·Android 실기기 확인은 미검증이다. 다운로드 후 사용 브라우저에 따라 로컬 저장/암호화 지원이 다를 수 있다.

## 전체 BLACKHOLE 연결의 남은 조건

- NVIDIA API: 로그인 화면의 다음 단계에 Developer Program 가입/Technology Access Terms 동의가 포함됨. 아직 동의·로그인·API 키 발급·Koyeb Secret 연결·실제 호출을 하지 않았다.
- 기존 API의 agent는 초안 작업만 가능하며 이번 결과는 현재 Codex가 구현했다. 무인 코드 실행자가 구현됐다는 증거가 아니다.
- 폰↔코어 공유 상태, 가족 관계 동의/철회, 실제 발송, 운영 코어 중단·재시작 검증은 후속 연결이다. 이후 A03와 B02-4의 다음 작업에 산출물 근거만 반영하고 재조회했다. 전체 프로젝트70개와 다른68개 행·원본 목표를 보존했다. 키·운영 배포는 변경하지 않았다. 확인 기록: `docs/PROJECT_DELIVERY_LIVE_20260911.json`.
- 이 파일에는 실제 API 키·가족 데이터가 없다. 백업 파일과 실제 사용 기록을 저장소에 커밋하지 않는다.
