# 실제 개발 상태 — 2026-09-09

[YENO 조종석](https://global-iris-gyeol-98386a17.koyeb.app/)에서 기억·문서·프로젝트·자료·운영 브리핑 기능을 사용할 수 있다. 노트북이 꺼져 있어도 상주 코어가 동작한다. 소유자 Android 캡처의 `코어 응답 확인됨`, revision 73으로 최초 기기 연결·상태 조회를 확인했다. 폰 명령·결과 열기·앱 종료/재실행 확인은 별도로 남아 있다.

기존 APK에서 `운영 브리핑` 또는 `운영 현황`을 보내면 접수 시점의 작업·진행 프로젝트·다음 작업·자료 검토·AI/개발 작업자 연결 범위를 실제 문서로 받는다. 외부 프로젝트를 자동 실행하는 명령은 아니다. [사용법과 검사 범위](OPERATIONS.md), [운영 초점과 확장 실험](OPERATING_FOCUS.md).

Android 최초 연결에서 관찰된 `Origin does not match Host`를 수정했다. 앱의 정확한 native Origin을 버전 API에 한해 허용하고 기존 인증·웹 출처 검사를 유지한다. 기존 APK를 재설치하지 않고 같은 입력으로 재시도할 수 있다. 수정·배포와 실기기 확인 범위는 [Origin 수정 기록](ANDROID_ORIGIN_FIX.md)을 따른다.

암호화 전체 백업·새 디렉터리 복원·소유자의 분실 기기 원격 폐기를 추가하고 배포했다. 실제 운영 프로젝트 20개·자료 76개·작업/결과 8개를 다른 파일시스템으로 내려받아 새 코어 프로세스에서 복원·모든 결과 해시·동일 요청 재전송을 확인했다. 원래 폰은 유지하고 시험 기기만 폐기했다. [복원 절차](BACKUP_RECOVERY.md), [전체 출시 기준](RELEASE_READINESS.md). 다만 백업 파일·키의 지속 보관 전송은 두 차례 모두 실패했다. 장기 보관 완료로 표시하지 않는다. 정기 백업·운영 호스트 자동 복구도 아직 없다.

## 비용 조치

기존 Koyeb `gyeol-openclaw/gyeol-gateway`는 승인에 따라 Pause했고 실행 0개를 확인했다. 새 YENO Micro 견적은 월 $5.36다. `hankki-anbu`는 기존 Supabase Free 조직으로 이전한 뒤 정상 실행·구조·함수 정의 일치를 확인했다. 향후 유료 Micro 상시 비용 약 $10/월을 피하는 추정이며 과거 사용분과 최종 청구는 별도다. Free 자동 정지와 Pro 백업 혜택 상실이 있다. Vercel Pro와 다른 DB는 유지했다. [상세 비용 기록](HOSTING_REUSE_AUDIT.md).

## 현재 한계와 다음 구현

실제 유료 AI 공급자·비용 한도 실검사, 일반 자연어 도구 루프, 개발 작업자, 정기 독립 백업 운영·운영 호스트 복구, Windows 파일·화면 제어, Windows EXE와 자율 개선 운영 배포는 미완료다. 단일 프로세스 JSON 저장소이며 여러 코어로 확장하지 않는다.

다음은 요청 ID 필수화·캐시 수명 이후 실행 식별자 보존을 보완한 뒤, 준비된 후보 하나를 격리된 개발 작업자 하나로 실제 구현·검사하고 결과를 YENO로 돌려주는 연결이다. 공급자·실행 환경·비용 상한이 확인되기 전 유료 실행을 켜지 않는다. Android 첫 명령·재접속과 정기 백업·운영 복구도 출시 조건으로 유지한다. 기존 노트북의 별도 0.2.3 설치와 데이터를 변경하거나 마이그레이션하지 않았다.

별도 `YENO 기능 발견` 예약은 일일 활성 설정이지만 최근/다음 실행 시각은 응답에 없어 실제 실행 성공은 미확인이다. 옛 PortfolioOps 작업 5개는 비활성이고 재활성화하지 않았다. 예약 후보 파일과 코어의 자동 동기화도 미연결이다.
