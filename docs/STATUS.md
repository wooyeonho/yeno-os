## 이번에 실제 확인한 것

Linux / Node 24.19.0에서 다음 명령을 실행했다. 외부 패키지 설치나 유료 모델 호출 없이 검사했다.

```bash
npm --offline run verify:baseline
npm --offline test
```

- 원본 무결성: runtime 0.1.1의 20개 파일 SHA-256·크기 일치.
- 기능 테스트: 19개 통과, 실패·생략 0개, 12.626초.
- 확인 범위: 인증·출처 제한, 잘못된 명령 거절, 중복 실행 방지, 기억 유지, 실제 문서 결과, 중단·재개·취소, 전체 정지, 동시성, 재시작, 단일 실행 잠금, 기억·설정 복원, 로컬 모형 공급자를 이용한 AI 연결 흐름.
- 이는 이 개발 작업 환경에서 실행한 검사다. GitHub Actions나 별도의 Codex Cloud 환경에서 실행한 결과가 아니다. 실제 유료 모델 공급자 확인도 아니다.
