# BLACKHOLE 연속 실행 목표 헌장 (Goal Charter) — 2026-09-30

작성: Claude(Cowork). 실행: Codex(연속 루프). 검증: Claude가 파일·해시·코드·회귀 로그로 독립 확인.
이 문서는 "무엇을 언제까지 어떤 증거로 끝났다고 말할 수 있는가"만 정한다. 구현 세부는 각 지시서(마스터 인계, S0 정정, 욕망 v3, S9~S20)가 우선한다.

## 0. 북극성과 현재 위치 (2026-09-30 14시 실측)

**북극성**: "모든 주장에 영수증이 붙는 자율 엔진" — 일곱 욕망·그림자·커비·JEV·양자가 **실제 기록**으로 움직이고, 그 결과를 누구나 재검증할 수 있게 만든다. 과장 0이 유일한 무기다.

현재(§148까지 검증): CP1 커넥터 패널·E1~E3·G1(초안함·예산·키 분리·GitHub 근거 검증기)·C1 색욕·C2 그림자·C3 커비·C5 양자 단일 결정·욕망 v3·C4 JEV 사건부 구현, 전체 회귀 1,398 / 1,377 통과 / 0 실패 / 21 스킵(체크포인트 ①). 진행 중: L5 통합 인수 + 전체 회귀 ②. 실검색 0건, 실제 모델 한 바퀴 0회, 실기기 0건, 미커밋 파일 200개 이상. 동결 3파일 무수정.

## 1. 목표 계층

- **O1 계획 완료**: S0~S8(+욕망 v3) 전부 구현·검증, 합성/실증 표기 완비.
- **O2 실증**: 실제 모델 키·실제 프로젝트로 한 바퀴 이상 돌려 "합성이 아닌 증거"를 만든다. 실제 출처 1개 이상이 원장(wealth/adoption/fame/honor)에 실측값으로 찍힌다.
- **O3 확장**: S9~S20을 순서대로. 끝나지 못한 항목은 삭제하지 않고 다음 구간으로 넘긴다(축소·삭제 금지).
- **O4 신뢰**: 어떤 보고도 검증 없이 완료로 세지 않는다. 진행률 = 검증된 수용 조건 수 / 전체 수용 조건 수(합성과 실증을 분리 집계).

## 2. 단계별 목표와 완료 정의(DoD)

**P0. 현재 배치 마감 (즉시)**
- 산출: L5 통합 인수(10단계, 인과 체인 gapId→inbox→capability/version/hash→runId→missionId→artifactHash→verdict), 전체 회귀 ②, §기록.
- DoD: 회귀 실패 0 / 스킵 21 초과 증가 없음 / 새 실패 원인 기록 / L5 각 단계에 실증·합성·BLOCKED 라벨 / 동결 해시 불변 / Claude 독립 검증 통과.
- 소유자 입력 없음.

**P1. 준비 기반 (S9 선행 항목)**
- 산출: 시험 3층 러너(fast <60초 / integration / full), 상태 등록부 설계 초안(코드는 소유자 승인 뒤), `docs/STATUS.json` 생성 스크립트(실행 기록에서 파생, 수동 편집 금지).
- DoD: 변경 파일→층 선택 시험, STATUS.json이 서브시스템별 실증/합성/미구현을 재현 가능하게 출력.

**P2. 실제 한 바퀴 (소유자 키 필요: 모델 키, 선택적으로 검색 키)**
- 산출: 실제 프로젝트 1개에서 감지→(조사)→결정→작업→검증→정산→화면까지 실증 1회 이상, 영수증 초안.
- DoD: 실제 모델 응답 로그(키 없음)·산출물 해시·정산 기록·화면 캡처가 모두 있고 "실증" 라벨, 합성 응답 0건, 실패도 그대로 기록. 키 미입력이면 BLOCKED로 남기고 P3로 진행.

**P3. S9 진짜 측정 → S10 밤 주기 → S11 그림자 실행 프로필** (회귀 ③ = S11 뒤)
- DoD 각각 지시서 수용 조건 그대로 + 원장에 실측 출처 ≥1(S9), 야간 창 밖 실행 0·모델 호출 0(S10), 역할 밖 도구 거부(S11).

**P4. S12 편재 → S13 교환소 → S14 영수증 페이지** (회귀 ④ = S14 뒤)
- DoD: 채널별 "못 하는 것" 표 통과, 위조 서명 거부, 영수증 재검증 스크립트가 변조를 잡음.

**P5. S15 제3자 검증 → S16 자기 개선 제안 → S17 무대 UI**
- DoD: 외부 검증자 서명 0건이면 "0건"으로 표시(부풀림 금지), 동결 파일 대상 제안 생성 단계 거부, 400/768/1440·모션 꺼짐 모드 정보 손실 0.

**P6. S18 설치·인프라 → S19 사업 층 → S20 공개 준비**
- DoD: 설치→상주→상태 API, 위조 업데이트 서명 거부, 재현 번들을 제3자 머신에서 재검증(불가하면 BLOCKED).

## 3. 진행 지표 (전부 실측 가능한 것만)

1. 전체 회귀: total / pass / fail / skip (fail 0 유지, skip 증가는 사유 필수).
2. 실증 대 합성: 수용 조건별 라벨 집계(STATUS.json).
3. 동결 3파일 SHA 불변(매 보고).
4. 원장 실측 출처 수, 실제 한 바퀴 횟수, 외부 검증자 서명 수(없으면 0 그대로).
5. 미커밋 파일 수(체크포인트 승인 대기).
6. 소유자 결정 대기 큐 길이.
새 점수·확률·"성공률"을 만들지 않는다.

## 4. 루프 규칙 (매 반복)

1. 최신 `## §`와 STATUS를 읽고 다음 미완 단계 하나를 고른다(순서 P0→P6, 소유자 입력 대기는 건너뛰되 큐에 기록).
2. 저장 먼저(옛 상태·옛 암호화 백업 복원 시험) → 구현 → 관련 시험만.
3. 전체 회귀는 P0 끝, S11 뒤, S14 뒤, S17 뒤, S20 뒤에만.
4. 단계마다 새 §번호(쓰기 직전 grep)로 VERIFIED / RAN-UNVERIFIED / BLOCKED, 산출물 SHA-256, 실패 로그 보존.
5. 하루가 끝나면 요약 §(무엇을 했고 무엇이 막혔고 소유자에게 필요한 것).
6. 체크포인트마다 소유자에게 커밋 승인을 요청한다(스스로 커밋 금지).
