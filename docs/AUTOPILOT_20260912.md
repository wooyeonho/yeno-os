# BLACKHOLE 상주 자동 운영

소유자가 2026-09-12에 매번 질문을 기다리지 말고 필요한 일을 먼저 실행하도록 명시했다. 기존 코어에 영속 자동 작업 선정기를 추가했다. 별도 개발 에이전트나 새 API 키가 필요하지 않다. 운영 활성화 여부와 실제 파일 증거는 STATUS와 AUTOPILOT_LIVE_VERIFICATION_20260912.json을 따른다.

웹 첫 화면은 **자동 운영**이다. 화면을 닫아도 서버가 실행하며, 다음 확인 시각·진행 중인 일·실패/연결 조건·저장된 파일을 표시한다. 기존 APK에서도 `자동 운영 시작`, `자동 운영 중지`, `자동 운영 현황`을 사용할 수 있다. 물리 기기에서 새 명령을 직접 시험한 상태는 아니다.

| 실행 | 자동 동작 | 경계 |
|---|---|---|
| God Eye | 시작 후 USGS/NASA 재난 자료 수집, 이후 6시간 간격 | 실제 공개 재난 자료만. 항공·선박·3D 아님 |
| EUREKA | 기존 E01~E09 중 다음 단계를 골라 근거 수집·답안 저장 | 연구 간격 6시간, 작업당 모델 1회, 자동 하루 최대 4회, 기존 전체 20회 안에서 공유 |
| 연구 진척 | 9트랙의 근거표 → 반증 검토 → 재현 계획 순환 | 이전 답안 파일·근거 해시 확인 후 진행. 총 27단계 뒤 실제 검증 자료를 기다리며 동일 초안을 무한 반복하지 않음 |
| 근거 데이터 | 원 응답 JSON, 근거 JSON/CSV, 인용 답안 저장 | 서지정보·초록·원문 미확인을 구분. 실험·난제 해결을 주장하지 않음 |
| For-Ai | 완료 연구를 개인 HTML 페이지로 만들고 구조 점검 | 하루 최대 1건, 추가 모델 0회. 원 연구 ID·답안 SHA 기록. 공개 게시·소유자 원문으로 오인하지 않음 |
| 영상 | 완료 연구의 질문·근거·검증 한계로 한글 텍스트 카드 MP4 생성 | 하루 최대 1건, 추가 모델 0회. 실제 H.264 720×1280, 무음. 임상 결론을 영상 문구로 자동 추출하지 않음 |

E05~E09의 원본 세부 가설이 미복원된 상태는 유지한다. 서지 검색과 검증 계획을 해당 원본 연구 성과로 승계하지 않는다. 소설의 유일한 기존 작품은 합성 인수검사 자료여서 자동 연재 입력으로 선택하지 않는다. 여기·한끼안부의 합성 기록도 실제 이용자 활동으로 세지 않는다.

자동 코딩·시험·배포 작업자, Grok Bot 제품 연결, 외부 게시·메시지 발송, 원본 세계관을 이어가는 무인 연재, 독립 지속 백업은 아직 별개 미완료 항목이다. 화면의 진행 조건에 이 사실과 실제 실패 작업을 표시한다. API 키만 추가했다고 위 기능을 완료로 바꾸지 않는다.

## 저장과 제어

- 설정·선정된 작업 ID·부모 연구·단계 식별자를 네트워크 전에 같은 상태 저장으로 확정한다. 한 번에 자동 작업 하나이며 이미 접수된 수동 작업을 먼저 처리한다.
- 정상 서버 재시작에서는 자동 운영 설정을 유지한다. 자동 작업 중 restart/shutdown 사유만, 유효한 기한과 호출 체크포인트가 확인될 때 같은 ID로 이어간다. 미확인/예약 모델 호출은 재전송하지 않는다.
- 소유자 중지·취소·기한 만료·실패한 연구 단계는 새 ID나 다음 날짜로 우회하지 않는다. 다른 연구 트랙은 정한 간격과 한도 내에서 계속할 수 있다.
- 전체 멈춤은 자동 운영을 끈다. 전체 멈춤 해제나 과거 시작 요청의 재전송으로 다시 켜지지 않는다. AI 모듈을 명시적으로 끄는 요청도 자동 운영을 끈다.
- 전체 백업/이전 상태 복구 후 자동 운영은 꺼진다. 새 상태·부모 관계·CSV/HTML 파일까지 엄격한 백업 검증을 통과해야 한다.
- 16MiB 전체 백업 한도에 대기 결과와 1MiB 여유를 포함해 입장 검사를 한다. 세계 관측에도 용량 예약을 적용한다. 한도에 닿으면 새 작업을 보류하며 기존 결과를 자동 삭제하지 않는다. 운영 용량 확장과 독립 지속 백업은 남은 작업이다.
- 하루 기준은 UTC다. 호출 횟수 상한은 실제 결제 금액 상한을 대신하지 않는다. 공급자의 기존 과금/프로젝트 한도는 유지한다.

## 검증 방법

`npm test`는 실제 HTTP·저장·인증·정지·복원·요청 중복을 검증한다. 외부 모델/문헌의 오류 조건은 합성 전송으로 검사한다. 한국어 MP4는 실제 ffmpeg/Pillow/Nanum 폰트로 따로 렌더링·디코딩한다.

`npm run verify:web`는 실제 임시 HTTP 코어와 배포 웹 코드를 사용해 로그인→자동 운영 시작 응답 유실→창 종료/재접속→같은 ID 확인→중지를 검사한다. 브라우저 DOM/cookie/Web Locks는 JSDOM 모의이며 실제 휴대폰 검증은 아니다.

운영 확인 명령 `node scripts/verify-autopilot-live.mjs --enable`은 고정 요청 ID로 자동 운영 설정만 제출한다. 이후 세계 관측·연구·For-Ai·영상 작업은 서버가 스스로 선정해야 통과한다. 동일 명령 재실행은 같은 설정 영수증을 확인한다. 인자 없는 실행은 상태 조회만 한다. 실제 키는 서버 환경에서만 읽고 출력하지 않는다.
