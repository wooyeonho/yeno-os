# 외부 코드 흡수·자동 코딩·음성 대화

## 사용

웹 왼쪽 **코드 흡수·자동 개발**에서 필요한 기능을 한국어로 입력하고 **코드 작성·시험·등록**을 누른다. 모델이 실제 JavaScript 파일을 작성하고 코어의 QuickJS WebAssembly 실행기가 고정 시험을 각각 두 번 실행한다. 실패하면 모델이 실제 오류를 받아 한 번 수정한다. 통과한 버전만 기능 목록에 활성화된다. **입력·실행·코드 수정**에서 다른 JSON 입력으로 재사용하거나 기존 코드를 고치고, 이전 버전으로 돌릴 수 있다. 작업별 최대 모델2회, 기존 전체 하루 호출 한도에 포함된다. 앱을 닫아도 접수한 코드 작업은 서버에서 실행된다.

직접 시험 입력·예상 결과를 넣으면 수정해도 그 기준은 바뀌지 않는다. 입력하지 않으면 모델이 만든 예시 시험을 쓰며 독립 품질 검증으로 표시하지 않는다. 시험 실패한 코드는 기존 활성 버전을 교체하지 않는다. 결과 문서와 실제 코드 묶음 JSON을 내려받을 수 있다.

**외부 코드 흡수**는 공개 GitHub 저장소 주소와 JS 파일 경로, 진입 파일, 라이선스 경로, 고정 시험을 받는다. 실제 원본을 40자리 커밋에 고정해 가져오고, 라이선스를 함께 보관한다. 가져온 코드는 우선 비활성 상태다. **시험 후 활성화**하면 같은 실행기에서 검증한 버전을 사용할 수 있다. 기존 모듈이 입력/출력 계약과 다르면 **AI가 코드 수정·재시험**으로 어댑터를 만들 수 있다. 수정본은 원본 커밋의 그대로인 코드가 아닌 AI 파생 코드라고 기록한다.

**자비스 음성 대화**에서 마이크를 누르고 한국어로 말한다. 인식 문장을 고쳐 **보내기**로 전송한다. **연속 대화**는 사용자가 켠 경우에만 말이 끝난 뒤 전송하고 실제 답변을 읽은 뒤 다시 듣는다. 현재 대화의 최근6개 발화만 다음 답변에 맥락으로 전달한다. 명령 실행 화면과 달리 음성 대화는 질문에 답하는 기능이며 외부 작업을 실행했다고 말하지 않는다. 음성 결과도 실제 작업 파일로 남는다.

마이크·읽기는 브라우저 Web Speech 기능을 사용한다. 브라우저에 따라 음성이나 답변이 제공 업체 서버로 전송될 수 있다는 안내 후 사용자가 마이크를 켠다. 미지원 브라우저에서는 문자 입력 또는 휴대폰 키보드 음성 입력을 사용할 수 있다. 음성 멈춤, 다른 탭 이동, 화면 숨김, 오프라인과 로그아웃은 듣기·읽기를 멈춘다. 이미 접수한 서버 작업은 별도 전체 멈춤/작업 중지로 제어한다. 휴대폰 마이크·스피커의 실제 동작은 실기기 검증 전이다.

## 실행 경계

실행기는 사전 정의된 표 연산을 넘어 실제 JavaScript 알고리즘·클래스·정규식·로컬 상대 모듈·Promise를 실행한다. 진입 모듈은 `run(input)` 또는 기본 함수를 내보내고 JSON을 반환한다. 코드 묶음과 입력 및 결과 보관 해시는 각각64KiB 이하, 파일16개 이하, 고정 시험2~8개다. 실행기 자체 출력 상한은256KiB지만 기능 등록·보관 계약은64KiB를 적용한다. 기능10개·버전30개·최근 이력500개 상한을 둔다.

별도 worker와 QuickJS WASM 인스턴스를 사용하고 게스트에 Node 파일·환경변수·네트워크·셸·운영 인증키를 제공하지 않는다. 시간 제한2초, QuickJS 메모리32MiB, 상주 코드 작업 동시1개다. 고정 시계와 난수를 사용해 시험 재현성을 유지한다. 작업 입력에 필요한 현재 시각은 명시적으로 전달한다. 이는 임의 언어·네이티브 바이너리·npm 설치·운영체제 제어·저장소 전체 자동 배포의 구현은 아니다.

코드와 검증 기록은 기존 영속 저장/암호화 백업에 포함한다. 복원 시 기능은 모두 비활성이다. 전체 정지와 AI 끄기, 호출 예약·미확인 응답 보존, 같은 요청 재접수 방지, 결과 해시 검사를 유지한다. 새로운 API 키나 유료 서비스는 추가하지 않는다.
