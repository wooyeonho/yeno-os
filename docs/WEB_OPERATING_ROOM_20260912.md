# BLACKHOLE 휴대폰 웹 운영실

기존 APK의 서명·기기 인증·보관소를 유지하면서 새 기능을 쓰는 경로다. 기존 APK를 삭제하거나 다른 서명 APK로 교체할 필요가 없다.

1. https://global-iris-gyeol-98386a17.koyeb.app/ 에서 기존 개인 연결 키로 처음 한 번 연결한다.
2. 개인 기기에서 연결 유지에 체크하면 브라우저를 완전히 닫아도 최대30일 연결된다. 끄면 서버 만료8시간의 세션 쿠키를 사용하며 브라우저 종료 때 먼저 끊어질 수 있다.
3. 운영실에서 For-Ai·여기·한끼안부·소설·영상, 세계 현황에서 God Eye를 사용한다. Chrome 메뉴의 홈 화면에 추가로 같은 웹 운영실을 연다. 홈 화면 설치 자체는 실제 휴대폰에서 확인하지 않았다.

로그인할 때 개인 연결 키를 기기별 HttpOnly 쿠키로 교환한다. 개인 연결 키는 localStorage/IndexedDB/산출물에 저장하지 않는다. 공개 HTTPS는 Secure·SameSite Strict·호스트 전용 쿠키를 사용한다. 서버가 만료와 기기 폐기를 확인하며 브라우저 인증으로 소유자 전용 백업·기기 관리 또는 네이티브 API를 사용할 수 없다. 로그아웃은 이 브라우저 기기만 폐기한다.

응답을 놓친 저장·제작·목표·명령·설정 변경은 전송 전에 정확한 요청을 로컬에 보관한다. 브라우저를 닫고 다시 열어도 같은 요청 ID로 확인하며, 이전 원고나 명령이 담긴 미확인 요청은 연결 해제로 지우지 않는다. 브라우저 사이트 데이터 삭제는 이 복구 기록을 제거한다. 여러 탭의 작업 기록 충돌을 막기 위해 한 탭만 운영실을 조작한다. 전체 멈춤은 미확인 저장 요청이 있어도 직접 보낼 수 있다.

서비스 워커는 공개 연결 안내와 스타일·아이콘만 보관한다. 인증, API 결과, 원고, 영상, 안부 링크는 캐시하지 않는다. 네트워크가 없을 때 새 작업을 받은 척하거나 백그라운드 전송을 약속하지 않는다. 서버에 이미 접수된 작업은 기존 상주 코어가 처리한다.

## 검증

- 로컬 Node24 전체301/301, 실패·생략0,28.852초. 실제 한글 MP4 검사 포함.
- 브라우저 인증 전용8/8: 실제 임시 HTTP 코어, 같은 등록 재시도, 쿠키 속성·서버 만료·변조·CSRF·권한 경계, 브라우저만 폐기하고 기존 네이티브 유지, 실제 문서/해시/재시작, 저장 실패 시 성공 미표시, 암호화 백업 복원 후 쿠키 폐기.
- `npm run verify:web`: 실제 웹 코드를 번들로 실행하여 로그인→장소 저장→응답 유실→브라우저 종료·재개→동일 요청 재시도→중복 없음, 기억 저장 동일 복구, 두 탭 충돌 차단, 로그아웃 응답 유실 후 새 로그인·정상 로그아웃을 검증한다. DOM·쿠키 저장·Web Locks·미디어 재생은 JSDOM 어댑터이며 실기기 검증과 구분한다.
- 실제 운영 배포·외부 HTTPS 증거는 `WEB_LIVE_VERIFICATION_20260912.json` 작성 후에만 그 기록을 따른다. 작성 전에는 이 문서만으로 배포를 주장하지 않는다.

## 기존 기능의 범위

영상은 실제 무음 한글 자막 MP4이며 생성형 영상·음성 API는 연결하지 않았다. For-Ai는 실제 페이지 구조 분석이며 검색 순위 보장은 아니다. God Eye는 USGS·NASA 공개 재난 현황이다. 한끼안부는 동의 기록과 직접 전달하는 수신자 링크이며 자동 발송하지 않는다. 소설은 설정·원고·회차·수정 이력·Gemini 집필·파일 내보내기이며 외부 연재 계정에 게시하지 않는다. Grok Bot 제품은 이 코어의 xAI 모델 어댑터와 별개이며 제품 계정 로그인·실행 연결이 남아 있다. 모든49개 제품이 완성됐다는 주장이 아니다.

기존 AI 하루20회, 자동 검토off, 프로젝트·자료 ID, 운영 볼륨을 유지한다. 이번 웹 접속 개선에 새 공급자 키나 새 호스팅은 필요 없다.
