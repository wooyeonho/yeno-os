# 문제의 답 · EUREKA 연구실

기존 BLACKHOLE 웹 운영실에서 **문제의 답 · EUREKA**를 연다. E01~E09 중 하나를 선택하고 질문을 입력한 뒤 **근거 수집·답안 만들기**를 누른다. 일반 문제는 별도 프로젝트를 만들지 않고 질문·영어 논문 검색어로 맡긴다. 폰의 기존 앱에서는 `연구: E02 | Long COVID 생물표지자를 검증하려면 무엇이 필요한가?` 형식도 사용할 수 있다.

접수한 작업은 서버에 남는다. 브라우저를 닫고 다시 열면 같은 작업과 결과를 확인한다. 응답을 놓치면 **같은 요청 접수 확인**을 눌러 최초 요청 ID로 확인한다. 새로운 요청을 자동으로 만들거나 완료 결과를 다시 생성하지 않는다.

## 실행 결과

- Europe PMC와 Crossref에서 각각 최대2개 문헌을 읽고 DOI 중복을 제거한다. API 키가 필요하지 않은 공개 검색이며 각 응답12초·512KiB 제한이다. Crossref는 journal-article 유형으로 한정해 부속 표·데이터셋의 혼입을 줄인다. 이 유형은 동료심사 여부를 보증하지 않는다.
- 원 응답 JSON과 SHA-256, 제목·제공 초록 최대1,200자·서지정보·철회/정정 표시를 근거 JSON으로 보관한다. 초록과 서지정보를 원문 열람으로 표시하지 않는다.
- 읽을 수 있는 문헌이 없으면 검색 실패 기록을 남기고 모델을 호출하지 않는다. 한 검색원 실패 시 나머지 근거와 실패 상태를 함께 보관한다.
- 기존에 연결한 모델을 **한 작업 최대1회** 호출해 잠정 답, 근거 표, 반론과 미확인 사항, 사전 동결·독립 검증 조건을 포함하는 다음 검증 하나를 작성한다. 기존 하루 호출 상한과 전체 멈춤을 따른다.
- 답안 Markdown과 원 응답·근거 JSON은 작업의 파일 버튼에서 열고 내려받는다. 근거에 없는 S번호를 인용하면 답안 완료로 승격하지 않는다. 호출 응답이 미확인이면 다른 모델로 재전송하지 않는다.

원본 49개 프로젝트와 추가 V11, 기존 프로젝트·자료 ID를 보존한다. E01~E09의 원본 목표를 새 이름이나 새 가설로 바꾸지 않는다. E05~E09는 세부 원본 가설 복원이 남아 있으므로 현재 질문에 대한 연구 초안을 원래 가설이나 과거 성과로 승계하지 않는다.

## 범위

이는 공개 문헌 근거를 모으고 검증 가능한 답안·다음 실험을 작성하는 연구 실행 기능이다. 검색 최대4건은 체계적 문헌고찰이 아니다. 원자료 통계 분석, 외부 코호트 검증, 실제 실험, 치료 효과 또는 인류 난제 해결 완료는 별도 증거가 필요하다. 반복 연구나 추가 모델 호출을 자동으로 예약하지 않는다.

E01은 ECDC primary / WHO GLASS의 사전 동결 후 독립 재현, E02는 사전 지정 다중표지자·독립 참여자/코호트, E03은 변수·척도·대상종·endpoint 동등성, E04는 단위·경계·영속성·비순환적 진척 검증을 유지한다.

## 검증과 운영

로컬 전체324/324, 실패·생략0. 실제 한글 MP4 필수 검사와 기존 웹 로그인·재접속·중복 방지 회귀검사를 통과했다. 연구 전용23개 검사는 공개 API·모델의 합성 응답으로 오류·예산·중단·암호화 복원 경계를 검증했다. 실서버 배포와 실제 모델 검증은 `RESEARCH_LIVE_VERIFICATION_20260912.json`이 생성된 이후의 증거를 따른다.

연구 작업에는 새 `researchRequest`·`researchEvidenceId` 필드가 있으므로 새 데이터를 만든 뒤 이를 모르는 구버전으로 코어를 내리지 않는다. 백업 복원은 연구 필드·원 응답 참조·해시를 검사하는 현재 버전을 사용한다. 기존 독립 지속 백업의 미완료 상태를 바꾸지 않는다.

API 계약: [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/), [Europe PMC 공식 WADL](https://www.ebi.ac.uk/europepmc/webservices/rest/application.wadl).
