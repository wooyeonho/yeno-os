# BLACKHOLE 독립 코어 최종 검증

검증 대상은 다음 실행 경계다.

- 모델 제공자 키가 없어도 코어 부팅, 상태 저장, 재시작 복구가 가능하다.
- 문서, 진단, 공개 관측, For-Ai, 로컬 영상, 검증된 커비 기능은 모델 없이 실행된다.
- JavaScript 생성·수리와 질문·음성·연구처럼 모델 응답이 필요한 작업만 명시적으로 모델을 호출한다.
- 운영 환경은 백그라운드 모델 호출을 허용하지 않는다.
- 자동 AI 회귀 검사는 `NODE_ENV=test`와 `YENO_DEVELOPMENT_BACKGROUND_MODEL_CALLS=true`를 명시한 개발 전용 구성에서만 실행된다.
- 새 작업 유형은 실행 경계에 등록되지 않으면 자동 실행하지 않는다.
- 이미 정산되고 초안까지 저장된 연구의 마지막 파일 저장 단계는 새 모델 호출 없이 완료할 수 있다.

최종 확인은 전체 런타임 테스트, 브라우저 로그인·요청 복구, 브라우저 재시작 후 연구 근거·답안 복구를 통과한 커밋을 기준으로 한다.
