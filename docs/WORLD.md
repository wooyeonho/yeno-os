# BLACKHOLE 세계 현황 — 첫 실행 기능

**2026-09-11 상태: 구현·158개 검사·GitHub 저장 완료. 자동 승인 검토가 기존 서비스 배포를 차단하여 아래 새 화면/명령은 운영 반영 전이다.** [검증·차단 기록](WORLD_VERIFICATION_20260911.json).

명령 `세계 현황` 또는 `지진 현황`은 USGS의 최근 24시간 M2.5+ 고정 공개 피드를 읽어 문서 작업과 결과를 만든다. 기존 Android APK의 명령/결과 계약을 사용한다. 웹의 **세계 현황**에서는 지도를 보고 규모로 필터링하고, 지점이나 목록을 눌러 원자료와 좌표를 확인한다.

## 수집·보존·제어

- API 키·AI 호출·사용자 위치·추적 쿠키 없이 한 공개 URL만 요청한다. URL 입력/임의 사이트 조회는 허용하지 않는다.
- HTTP 리다이렉트 차단, 12초/512KiB 제한, 자료형·발생 시각·좌표·규모·중복 ID 검증. 잘못된 행과 표시 한도 제외 수를 따로 표시한다. 최대 100개 최신 사건.
- 60초 이내 기존 결과는 같은 조회 시각 그대로 재사용한다. 원자료 생성 후 15분을 넘으면 지연으로 표시한다. 실패 시 이전 결과를 유지하고 실패 상태를 함께 표시한다.
- 조회는 지속 요청 ID가 있는 작업이다. 중단은 실제 요청을 abort하고 늦은 응답의 완료 반영을 막는다. 재시작은 미완료 작업을 일시정지한다. 완료 결과는 원자료 해시와 함께 저장한다.
- 세계 결과의 제한된 스냅샷과 문서를 암호화 백업/새 디렉터리 복원에 포함한다. 복원은 전체 정지 상태이며 새 호출을 하지 않는다. 이 새 작업 유형이 생긴 상태는 이전 코어 버전의 복원 입력으로 쓰지 않는다.
- 정기 위치 감시·자동 알림·긴급 경보·항공/선박/위성 연결·God Eye 원본 코드 통합은 하지 않았다. God Eye 링크의 읽기/판단 상태는 그대로다. 기존 목표에서 공개 데이터 한 종류를 자체 구현한 것이다.

## 원 제작자와 조건

- 데이터 계약: https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php (2026-09-11 확인).
- 실제 피드: https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/2.5_day.geojson
- 지도 조건: https://www.naturalearthdata.com/about/terms-of-use/ (public domain 설명 확인). 로고·외부 사진·제작자 코드를 복제하지 않았다.
- 지도 원 데이터: https://github.com/nvkelso/natural-earth-vector/blob/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_110m_land.geojson — 127개 육지 Feature를 경위도 등거리 투영 SVG로 변환해 번들에 포함. 동적 타일 호출/지도 SDK 의존성 없음.

USGS가 보고한 관측 범위이며 모든 지역의 모든 지진을 빠짐없이 실시간 표시한다는 뜻이 아니다. 원자료의 자동 판독·수정 상태와 실제 시각을 표시한다. 개인 안전 판단을 제공하지 않는다.

## 검증

피드 형식·시간·크기·위험 링크 제거, 명령→실제 결과/해시, 같은 요청 재사용, 캐시 시각 보존, 재시작·새 디렉터리 복원, 중단 후 늦은 응답 방지 검사를 추가했다. 전체 검사와 실제 Koyeb HTTPS 결과는 STATUS 및 후속 운영 증거를 따른다. 이 환경의 브라우저가 localhost 미리보기를 차단했으므로 브라우저 화면/Android 실기기 조작은 API 검사와 구분한다.
