# BLACKHOLE 독립 OS 실행 경계

## 불변 조건

BLACKHOLE의 평상시 코어는 모델 제공자 없이 기동하고 계속 작동한다. 목표 후보의 규칙 기반 순위, 스케줄링, 요청 중복 방지, 상태 저장, 검증된 기능 실행, 결과 해시 확인, 중단·재개, 백업·복구는 로컬 런타임이 담당한다.

외부 AI는 코어가 아니라 명시적으로 호출하는 가속기다. 다음 경우에만 사용한다.

- 연호님이 질문·음성 대화·연구 실행을 직접 접수한 경우
- 연호님이 코드 작성·수정을 직접 접수한 경우
- 개발 과정에서 별도 도구가 소스 변경안을 만드는 경우

환경에 API 키와 과거 `YENO_AGENT_AUTORUN=true`가 남아 있어도 자동 연구, 자료 갱신 뒤 자동 검토, 백그라운드 모델 호출은 시작하지 않는다. 연결된 키는 수동 요청을 실행할 준비 상태만 뜻한다.

## AI 없이 계속 실행되는 범위

- 호문쿨루스: 저장된 지표와 규칙으로 허용된 목표 후보의 우선순위를 계산
- 커비: 이미 검증·활성화한 선언형 기능과 QuickJS JavaScript 기능 실행
- 자비스 코어: 작업 큐, 요청 원장, 파일 결과, 상태·오류·복구 정보 제공
- 공개 관측, 내부 문서 변환, 진단, 결과 재사용, For-Ai 점검, 로컬 영상 렌더링
- 종료·재시작 뒤 저장된 작업과 결과 복구

이미 모델 응답이 정산되어 최종 답안 체크포인트가 남아 있다면 새 호출 없이 파일 저장 단계를 마칠 수 있다. 새 모델 응답이 필요한 자동 작업은 시작하거나 재개하지 않는다.

## 명시적 호출의 경계

수동 호출도 기존 하루 호출 상한, 요청 ID, 호출 원장, 미확인 응답 재전송 금지, 전체 멈춤을 그대로 적용한다. AI를 끄거나 키가 없어도 독립 코어와 비-AI 기능은 중지되지 않는다.

## 독립의 의미

이는 모델 API로부터의 실행 독립성이다. 공개 관측처럼 네트워크 자료가 필요한 기능은 인터넷 연결이 필요하고, Koyeb 배포본은 Koyeb 인프라에서 실행된다. 운영 서버 재배포와 실제 휴대폰 검증은 소스 구현·자동 검사와 별도로 확인한다.
