# EXTRA-136 Shadow 산출물 사전 평가 기준

작성: 2026-09-27, 새 실모델 임무 실행 **전**. 이 기준은 EXTRA-136 한 과제의 결과 품질을 보기 위한 것이며 Shadow Army 모든 임무에 적용하는 보편 문서 형식이 아니다. 원장의 `four-inputs.json`과 기존 `m2-shadow-builder-context-live` 기록은 부분 열람 자료다. 영상 원문, 사용 기기·엔진, 실제 깊이 가림 장면은 확인하지 못했다. 아래의 장면과 시험은 **새로 제안하는 독자 에셋 실험**이지 원본 영상의 내용이라는 주장이 아니다.

## 과제

“독자 에셋 최소 장면의 깊이 가림 시험 조건과 미확인 항목을 구분한 한국어 작업 카드 1개.” 최종 산출물은 조사 계획이나 교육 제안만이 아니라, 제작자가 바로 작은 장면을 만들고 검증할 수 있는 작업 카드여야 한다.

## 모든 항목을 충족해야 내용 합격

1. **범위와 출처:** EXTRA-136 소스 ID 또는 원장 ID, `partial/pending` 성격, 원본 영상·기기·엔진 미확인을 적는다. 특정 영상 장면을 직접 보았거나 특정 엔진에서 시험했다고 주장하지 않는다.
2. **입력:** 독자 배경·전경 가림 물체·이동 대상(또는 카메라)의 최소 에셋, 화면상 상대 위치/깊이 순서, 움직임 경로를 구체적으로 제안한다. 새 독자 에셋과 미확인 원본을 구분한다.
3. **상태와 출력:** 대상이 가림 물체 앞에 있을 때, 뒤로 들어갈 때, 다시 나올 때의 세 상태를 적고 각 상태에서 화면에 보여야 할 부분과 가려져야 할 부분을 적는다. 캡처 이미지 또는 짧은 영상 등 확인 가능한 산출물을 지정한다.
4. **검증과 실패:** 고정 시점·움직이는 시점 또는 경계 통과를 포함한 최소 2개 시험 조건과 눈으로 판정할 수 있는 합격/불합격 기준을 적는다. 예: 뒤에 있어야 하는 대상이 전경 물체 위로 새어 보이면 실패. 실제 시험을 아직 실행하지 않았다고 명시한다.
5. **실행 카드:** 한 장의 한국어 카드에 작업 순서, 필요한 산출물, 검토 근거, 미확인 조건을 담는다. “추가 조사/교육이 필요하다”만으로 끝나면 불합격이다. 의미 검증기가 `pass`를 내더라도 실제 제작/시각 시험의 완료로 승격하지 않는다.

## 판정 방법과 증거

기계적 검사는 임무·작업·산출물 ID, 저장 SHA-256, 모델 호출 정산, 재시작 보존을 확인한다. 독립 의미 검증은 위 다섯 항목에 비춰 초안을 판정한다. 단일 `pass`를 과신하지 않도록 사람이 산출물 본문과 근거를 읽어 각 항목을 별도로 기록한다. 출력 형식 오류는 내용 평가와 따로 기록한다. `uncertain` 또는 `fail`은 결과를 보존하되 완료로 세지 않는다.

2026-09-26의 기존 Builder 산출물은 작업 카드가 두 개이고, 입력/상태/출력/시험의 관찰 가능한 기준이 없으며 원장·영상 직접 확인을 암시한다. 이 사전 기준에서 내용 불합격이다. 새 시험이 실패하면 같은 모델 호출을 숨겨 다시 쓰지 말고 실패 원인과 예산·자원 사용을 남긴다.
