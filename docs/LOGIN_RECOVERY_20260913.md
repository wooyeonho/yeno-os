# 접속 복구와 자동 운영 재시작 수정 — 2026-09-13

## 확인된 문제

소유자 화면은 웹 개인 연결 키 로그인에서 401을 받았다. 정상 서버 상태는 로그인 성공을 입증하지 않는다. 해당 응답은 등록 요청 본문·쿠키 처리 이전의 키 비교 실패다. 실행 환경 키는 16자·ASCII·앞뒤 공백 없음이며 Koyeb의 지정 Secret을 참조한다. 이 사실만으로 소유자가 입력한 값과 같다고 판단하지 않는다. 비밀값은 저장·출력하지 않았다.

## 코드 변경

- 로그인 실패를 키 불일치, 헤더 미전달, 횟수 제한, 오래된 등록으로 구분한다. 잘못된 키는 그대로 거절하며 인증을 약화하지 않는다.
- 앞뒤 공백·짧은 키·전송 불가능 문자를 입력 단계에서 안내하고 키 보기/숨기기를 제공한다. 페이지 숨김·종료 시 표시를 닫는다.
- 인증된 만료/해제 등록만 한 번 새 등록을 만든다. 응답 유실·일반 충돌은 같은 접수 ID와 미확인 작업을 보존한다. 유효한 HttpOnly 쿠키는 다음 접속에 다시 사용한다.
- 자동 연구가 최종 답안을 저장한 뒤 재시작되면 모델 설정이 없어도 그 답안의 파일 저장을 마무리한다. 추가 모델 호출 없이 같은 작업과 바이트를 보존한다. 소유자 중지·기한 만료·미확인 호출은 계속 차단한다.
- 배포별 실제 HTTPS 로그인 검증 스크립트를 추가했다. 이미 끝난 검사 접수증을 새 성공으로 간주하지 않고 검사 기기만 정리한다.
