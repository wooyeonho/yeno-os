JEV의 현재 `calibrateShadowLog`에서 `matchRate`의 분모는 **결정한 표본**(`byStatus.decided`)이고, `falsePositiveRate`의 분모는 **전체 표본**이다. 새 Wilson 하한은 결정한 표본의 일치 정수 건수를 로그에서 직접 세어 계산하고, 빈 표본은 `null`이다. 기준인 기존 scheduler와의 일치율은 정답률의 독립 검증이 아니며 같은 임무에서 나온 관측은 독립 표본이라고 보장되지 않는다. 따라서 이 수치만으로 JEV에 보류·디스패치 권한을 주지 않는다. `authorizesDispatch:false`가 유지된다.

양자 격리 실험의 입력은 실제 `buildRecoveryOneOfCircuit` 결과의 QASM과 지문이다. `scripts/verify-quantum-open-source.mjs`는 합성 JEV 컨텍스트에서 3대안 회로를 생성해 64격자·1024 shots를 실행하며, `q1-quantum.json`과 `q1-sweep.csv`를 남긴다. 보고서 내부 `selection.selectionSource:'qpu_counts'`는 기존 decoder의 분류명일 뿐 **하드웨어 QPU 측정이 아니다**. `countsOrigin:'local_statevector_simulator'`와 evidence class가 실제 출처다. 모델·QPU 계정·외부 제출 없이 로컬 시뮬레이션만 했다. **현재 운영 JEV 회복 입력은 `wait`·`owner_review` 2대안의 비용이 둘 다 0이라 기존 `checkedDecisionContext`가 `classical_fallback_required`로 양자 선택을 거부한다.** 이 비용을 임의로 만들어 연결하지 않는다. 실제로 서로 다른 측정 가능한 목적값이 있는 승인된 복구 상황을 찾은 뒤 job/restart/backup 경계와 고전 fallback 권위를 추가 검증해야 한다.
