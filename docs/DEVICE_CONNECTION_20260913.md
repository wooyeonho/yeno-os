# 기기 승인 방식으로 접속 재구축 — 2026-09-13

기본 접속을 `이 기기 연결 → 소유자 확인 → 운영실 자동 열림`으로 새로 구현했다. 기존 키 입력은 보조 방식이다. 브라우저의 요청 번호만으로는 로그인할 수 없으며 서버의 기존 소유자 인증으로 해당 요청을 승인해야 한다. 브라우저 증명은 HttpOnly 쿠키에만 저장되고, 요청은 10분 후 만료된다. 연결 유지는 기존 30일/8시간 정책을 따른다.

운영자 승인: 기존 코어 콘솔에서 `node scripts/approve-browser.mjs <요청 번호>`를 실행한다. 실제 연결 키를 대화나 명령에 입력하지 않으며 현재 환경의 키로 인증한다. 원하지 않은 요청은 승인하지 않는다. 새 연결에는 소유자 확인이 필요하다.

응답 유실 시 같은 요청/기기로 재확인한다. 서버 재시작은 대기 요청만 만료시키며, 이미 발급된 연결과 작업·결과·기억·네이티브 기기·API 설정은 보존한다. 로그아웃/폐기된 기기는 이전 요청으로 되살리지 않는다. 승인 뒤 접속 여부가 불명확한 기기는 자동으로 폐기하지 않으며 기존 등록 수 제한을 적용한다.

범위: 접속 흐름 재구축이다. 전체 프로젝트를 새로 완성했다거나 휴대폰 실기기 접속이 성공했다고 표시하지 않는다. 운영 적용 및 실제 브라우저 결과는 별도 증거로 갱신한다.
