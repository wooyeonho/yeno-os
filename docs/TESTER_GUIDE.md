# BLACKHOLE 외부 테스터 안내 초안

이 문서는 테스터 10명에게 보낼 **초안**이며 아직 배포하거나 연락하지 않았습니다. 저장소 라이선스·설치 파일 서명·소유자 공개 승인 전에는 외부 배포하지 않습니다.

1. 테스트 전 설치 파일의 출처, SHA-256, 서명 주체를 확인합니다. 현재 공개 설치 패키지는 확정되지 않았습니다.
2. 별도 시험 환경에 설치하고 실제 계정·결제정보·민감한 파일을 입력하지 않습니다. 페어링 비밀값을 채팅이나 캡처로 공유하지 않습니다.
3. 사용 허가를 받은 경우, Android에서 한 작업을 요청하고 Windows에서 실행·진행·결과·재시작 복구를 확인합니다. 각 단계의 시간, 표시 문구, 실패 이유를 기록합니다.
4. 문제가 생기면 앱의 전체 멈춤을 사용하고, 기대한 동작과 실제 동작을 [양식](TESTER_FEEDBACK.md)에 기록합니다. 화면 캡처의 개인정보는 지웁니다.

테스터 모집·메시지 전송·설치 안내 전달은 아직 하지 않았습니다. 현재 실기기 페어링 수락은 미검증입니다.
