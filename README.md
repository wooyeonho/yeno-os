# BLACKHOLE

BLACKHOLE은 소유자가 원하는 결과를 Android나 PC에서 요청하면 Windows 코어가 계획·작업·검증 기록을 남기고 진행 상황과 결과를 돌려주도록 개발 중인 개인 AI 운영체제입니다. Jarvis는 화면과 대화, Kirby는 검토된 능력 재사용, Seven Drives는 우선순위, Shadow Army는 역할별 작업, JEV는 근거 검토를 맡습니다.

현재 저장소의 코드·합성 시험·격리 Windows 시험은 **실제 휴대폰에서의 페어링→요청→PC 실행→결과→재시작 복구**나 실제 모델의 장기 작업 품질을 증명하지 않습니다. 아래 표에서 `synthetic`은 가짜 공급자 또는 격리 데이터를 뜻하고, `external`은 명시된 외부 읽기 근거에 한정됩니다. `implemented`도 제품 전체의 실사용 완료를 뜻하지 않습니다.

## 5분 확인

Node.js 20 이상과 npm이 필요합니다. 저장소를 검토한 뒤 아래 명령으로 로컬 회귀를 실행할 수 있습니다. Windows에선 `npm.cmd`를 쓰면 됩니다.

```powershell
npm.cmd ci --prefix runtime --ignore-scripts --no-audit --no-fund
npm.cmd test
node scripts/status-from-log.mjs --check
node scripts/public-status.mjs --check
```

기능별 근거의 정본은 [실행 기록](docs/CLAUDE_EXECUTION_STATE.md)이며, [상태 JSON](docs/STATUS.json)은 그 기록의 STATUS 행에서 생성됩니다. 표의 `build-artifacts/` 링크는 해당 로컬 시험을 실행한 작업 공간에서만 열립니다. 실제 키나 페어링 비밀값을 저장소·채팅·로그에 넣지 마세요. 비공개 미션 영수증과 공개 재현용 **합성** 번들은 별개의 자료입니다.

## 경계와 참여

소유자 승인 전에는 외부 코드의 실행 경로 활성화, 공개 게시, 실제 영수증 공개를 하지 않습니다. [테스터 안내](docs/TESTER_GUIDE.md), [기여 규칙](CONTRIBUTING.md), [보안 신고 안내](SECURITY.md)를 참고하세요. [공개 라이선스 결정](docs/PUBLIC_LICENSE_DECISION_PENDING.md)은 아직 소유자가 하지 않았습니다. 의존성별 라이선스와 저장소 전체의 재배포 허가는 다릅니다.
